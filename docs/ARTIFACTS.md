# ELDOR code release

This is the anonymous review version of the ELDOR benchmark.

This repository provides source code, model configurations, dependency snapshots,
evaluation scripts, and result tables. Dataset files and trained checkpoints are
not distributed in this code release.

To run an experiment with locally available data, configure the paths in
[REVIEW_SETUP.md](REVIEW_SETUP.md). Pretrained upstream model dependencies are
documented in [METHOD_SOURCES.md](METHOD_SOURCES.md).

Data splits, class identifiers, patch filenames, and reported measurements retain
their original scientific meaning. The ELDOR name is retained throughout review.
